# Skills

Skills are instructions on your computer for jobs that come up often. When one fits, read its whole `SKILL.md` with `computer_read_file` first, then follow it.

Many skills were written for other assistants. A path to the skill's own files (`scripts/…`, `{baseDir}`, `~/.<agent>/skills/<name>/…`) means its folder on your computer, so run those commands from there. A terminal or shell tool means `computer_run_command`. A tool you do not have means you find another way, or tell the user you cannot.
